# Code and source data for pore-regulated heterogeneous nucleation

This repository contains the code, source data, representative simulation
snapshots, ESEM source images, and movie metadata assembled for the associated
PNAS manuscript on pore-regulated heterogeneous nucleation.

The repository is organized to support the main theoretical model figures and
to document the additional MDS and ESEM evidence described in the main text and
SI Appendix.

## Repository contents

- `code/calculate_collision_rates_Fig3.m`: calculates the surface migration
  collision rate, gas-phase direct collision rate, and ratio used in Fig. 3B-D.
- `code/calculate_kelvin_constraints_Fig4.m`: calculates the generalized
  Kelvin constraint curves used in Fig. 4A.
- `code/plot_potential_energy_map_Fig2B.m`: re-exports the particle surface
  potential-energy cloud map from the included Fig. 2B source image.
- `code/analyze_MD_clusters_Fig1_Fig2_Fig4.m`: indexes representative MDS
  snapshots and movie files, and exports a snapshot overview contact sheet.
- `code/cnt3.m`: calculates Kelvin-consistent CNT free-energy curves for the
  dual-particle pore and equal-area single-particle reference at selected
  ambient saturation ratios.
- `data/Fig3_collision_rates/`: CSV source data generated by the Fig. 3
  collision-rate script.
- `data/Fig4_kelvin_constraints/`: CSV source data and intersection tables
  generated by the Fig. 4 Kelvin-constraint script.
- `data/Fig2_potential_energy_source_data/`: source images and PDFs for the
  potential-energy cloud maps for 2-2 nm, 2-4 nm, and 2-10 nm particle systems.
- `data/Free_energy_CNT/`: dual-particle and single-particle free-energy curve
  data, Kelvin key points, mapped free-energy key points, detected extrema,
  and summary tables exported by `code/cnt3.m`.
- `data/representative_MD_snapshots/`: representative MDS visualizations,
  including the SI Fig. S1 three-system overview, 2-2 nm and 2-4 nm time
  snapshots, 2-10 nm model/summary images, Origin workbooks, and small source
  archives for the 2-2 nm and 2-4 nm visualizations.
- `data/ESEM_movie_metadata/`: ESEM/SI source images, available MP4 files,
  movie legends, extracted first-frame previews, sampled movie-frame previews,
  and a movie metadata table.
- `figures/`: generated and manuscript-reference figures, including
  `generated_Fig3B.png`, `generated_Fig3C.png`, `generated_Fig3D.png`, and
  `generated_Fig4A.png`, plus `CNT_FE_keypoints_free_energy_600dpi.png` for
  the SI free-energy calculation.
- `source_file_manifest.csv`: file-level manifest for the curated repository.
- `LICENSE`: current use-permission statement.

## Software requirements

The MATLAB scripts were kept compatible with MATLAB R2018b or later and use
standard MATLAB functions. No third-party MATLAB toolbox is required for the
theoretical calculations.

The MDS snapshot and movie metadata tables were generated during repository
curation using local file metadata. The MP4 metadata was read with OpenCV only
to create the repository index and preview frames; OpenCV is not required to
run the MATLAB scripts.

## How to reproduce the theoretical outputs

From MATLAB, run the scripts from the repository root or from the `code/`
directory:

```matlab
run('code/calculate_collision_rates_Fig3.m')
run('code/calculate_kelvin_constraints_Fig4.m')
run('code/plot_potential_energy_map_Fig2B.m')
run('code/analyze_MD_clusters_Fig1_Fig2_Fig4.m')
run('code/cnt3.m')
```

The original Fig. 3 and Fig. 4 calculation scripts write their outputs to the
current MATLAB working directory. Reference copies of their generated outputs
are already included under `data/Fig3_collision_rates/`,
`data/Fig4_kelvin_constraints/`, and `figures/`.

The free-energy script uses a 2.0 nm dual-particle radius, a 2.828 nm
equal-area single-particle radius, a 30 degree contact angle, and 273.15 K.
The included reference calculation evaluates ambient saturation ratios of
1.29, 1.39, and 1.59. It writes its outputs beside the script; curated copies
are included under `data/Free_energy_CNT/` and `figures/`.

## Data notes

The SI Appendix states that the MDS systems include 2-2 nm, 2-4 nm, and
2-10 nm particle models. This repository includes representative visualization
source files for all three systems. For the 2-2 nm and 2-4 nm systems, the
Desktop search also found time-resolved PNG snapshots and small source
archives, which are included here. For the 2-10 nm system, the files found on
the Desktop were the SI overview/model images, potential-energy map, summary
plot, and Origin/Excel summary files; a matching full trajectory or complete
time-snapshot directory was not found during this curation pass.

The ESEM movie folder contains all MP4 files found on the Desktop plus
metadata and preview frames. One file appears to be an ESEM-like grayscale
movie of concave/pitted particles and is a likely Movie S3 candidate. The
other two MP4 files are desktop/OVITO recordings based on preview frames. The
final mapping of Movies S1-S3 should be verified before PNAS submission, and
missing final ESEM movie files should be added if they exist outside this
Desktop search scope.
